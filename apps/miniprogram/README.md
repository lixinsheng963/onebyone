# 校园日常 · 微信小程序端

原生微信小程序，无构建步骤。用微信开发者工具打开本目录即可运行。

## 运行

1. 微信开发者工具 → 导入项目 → 选择 `apps/miniprogram`。
2. AppID 可用测试号；`project.config.json` 默认 `touristappid`。
3. 详情 → 本地设置 → 勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”（仅在接本地 API 时需要）。
4. 默认使用本地 mock 数据，不需要启动 API。

## 演示路径

- 首页：最新 / 热门 / 精选、紧急通知、校方通知、话题筛选
- 详情：图片预览、点赞/收藏、评论/回复、匿名开关、举报
- 发布：1–9 图、文字、话题、地点、匿名、允许评论、草稿
- 认证：微信登录 → 邀请码 `CAMPUS` / 现场码 `CAMPUS`
- 我的：发布/评论/收藏、通知、设置、社区公约、申诉
- 管理后台不在本目录，见 `apps/admin`

## 接本地 API

把 `utils/config.js` 的 `useRemote` 改成 `true`，启动根目录 API：

```bash
pnpm dev:api
```

开发者工具需关闭合法域名校验，因为本地 API 是 `http://127.0.0.1:3000`。生产必须换成备案 HTTPS 域名。

## 图片

`assets/images` 是本地生成的抽象占位图，`assets/icons` 是 tabBar/操作图标；上线前替换成真实校园照片和学校授权视觉素材。
